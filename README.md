# Reproducibility_JPSP_Steinmetz2016
R-based reproducibility project for Steinmetz et al. (2016) "Being Observed Magnifies Action", published in JPSP. Includes data cleaning, analysis, and visualization.

Citation
Steinmetz, J., Xu, Q., Fishbach, A., & Zhang, Y. (2016). Being observed magnifies action. Journal of Personality and Social Psychology, 111(6), 852–865. https://doi.org/10.1037/pspi0000065

Data Source
The raw data and original materials can be found on the Open Science Framework (OSF) : OSF Project: https://osf.io/gfytw/overview

Environment
R Version: 4.5.2
